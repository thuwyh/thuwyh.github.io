这周决定换个写法，先让AI把我刚经历的一切梳理成问题，然后再把答案拼接成故事。主题集中在两个瞬间：一个是抓住 vibe coding 这股风，另一个是在三番的 Tech Week 感受到的AI热浪。

## Vibe coding 让效率坐火箭

尝鲜 vibe coding 其实并不是一个突如其来的决定。之前一直在用 Copilot 当补全工具，偶尔切换到问答模式解题；Codex 则帮我撸过一些独立功能。本周被同事疯狂安利，终于认真试用了 Claude Code。真正的契机是最近开了几个需要完整端到端体验的 side project：算法做完了，总得有个前端去展示。以前这种需求我会用 Gradio 将就一下，但扩展性、体验都差点意思。现在模型写前端的能力明显升维，索性试试看。

事实证明，Claude Code 的体验的确对得起“vibe coding”这三个字。不只是模型本身换挡提速，更是整套产品设计承载起了新的工作流。同样的问题扔在 Copilot 的 agent 模式里用Claude Sonnet 4.5就是搞不定，在 Claude Code 里却能稳稳落地。工程化能力、上下文调度、交互节奏，这些外围细节直接决定了“模型能力”能否发挥出来。

## Claude Code：第一次把额度用爆的工具

这是第一次我把一个 20 美元的月度套餐刷出“session limit”。用 Claude Code 紧张工作三个小时就打满了 session，周额度瞬间消耗 16%。这在 Copilot、Codex 身上从未发生过。站在生产力角度也能感受到质变：一个晚上交付了 5700 行代码。我保守估计这相当于以前一周在非常熟悉领域的输出。算一笔账：硅谷中级程序员十来分钟的工资，换来“整周产出”，到底是 AI 便宜还是人类昂贵？更讽刺的是，在国内就算找水平一般的外包，一人天也得四百块人民币。

![三小时就到Session Limit](/assets/aiweekly/20251011-1.jpg "三小时就到Session Limit")


当然，“高效率人士效率更高”只是结论的一面。另一个严肃的问题是：我们需要重新审视自己的技能栈和时间配置。木桶理论正在被改写——如果某块短板 AI 可以补，那就别再死磕了。比如后端程序员为了独立开发硬啃前端，如今的 ROI 已经低得可怜。我的 vibe coding 达人朋友甚至拿 Claude Code 写完了申请日本签证所需的材料并用浏览器填表提交，证明这类工具已经具备了让人眼前一亮的通用性。

## 调教模型的门槛正在上升

Claude Code 能够“稳”还有一个被低估的原因：我特意读了官方的最佳实践博客，照着写了 CLAUDE.md，把上下文、约束、样例、待办拆得清晰。指令质量上来之后，废话、绕弯、跑偏的概率显著下降。但也不是一招鲜就能吃遍天，我遇到一两个小细节就是搞不定，没想到Codex一下就搞定了。可见丰富的工具箱很重要，多模协作和 prompt 工程也成为新的基本功。

这套体验让我意识到未来的曲线：模型封装得越好，我们越容易忽略“指令设计”这项无形劳动力。但只要想让 AI 进入深水区，就得认真琢磨如何描述任务边界、如何留出自检空间、如何让模型理解业务语境。AI 编程进入“有准备的人”的时代，专业的 prompt 工程或许会重新被重视。（前几天也看了下最近爆火的speckit，也是这个意思）

## San Francisco Tech Week：三番的密度与热度

Tech Week 的日程排得密不透风，我本来报了好几个活动，最后阴差阳错只去了两个。第一个是 Xpectrum AI 办的 **Agentic AI: Building the Next Wave of AI Agent**。噱头十足，可惜内容像是把 livekit 套了个 agent 壳，主打打电话接电话，这类玩法我们几个月前就玩烂了。创始人的 pitch 也比较平，听了会我就和朋友撤退了。不过现场仍然挤满了几十号人，证明“AI agents”这个关键词依旧足够吸引真金白银。

![Xpectrum的Pitch](/assets/aiweekly/20251011-2.jpg "Xpectrum的Pitch")


第二场 **Agents Everywhere: From Workflow to Connectivity** 才是正餐。四家公司：E2B、Composio、AGI 和 Pokee，同时也是我这一周内第二次遇到 Bill。他这次聊 MCP 的观点跟我之前的观察高度一致：API 生意本身并不好做，RapidAPI 这种交易平台过得并不潇洒。掌握核心能力的公司是否开放 API，要看商业算计；很多关键功能未必上架，也就很难支撑一个“tools 上架平台”。但“AI native 的 tool”是真问题，今天市面上绝大多数 API 都不是给 AI 设计的，工具对齐这件事还有大量工程空间。

![这场质量高很多](/assets/aiweekly/20251011-3.jpg "这场质量高很多")


## 为什么是旧金山？

旧金山只有八十多万人口，比上海闵行区还少了一半，开车几十分钟就能横穿。但整座城市像被开了挂。到处都是 AI 广告，咖啡店、街角甚至路人的聊天主题都是最新的模型、融资、应用。创业者、VC、builder 在同一个地理空间里持续碰撞，密度高得让人目不暇接。有兴趣的朋友可以去科技周的网站 https://www.tech-week.com/calendar/sf 感受一下。

![Tech Week首页](/assets/aiweekly/20251011-4.png "Tech Week首页")


与其说是“活动”，不如说是情绪。大家对 AI 的热情、对机会的渴望、对产品的打磨都在这个城市里不断发酵。这个氛围和我在其他科技城市的体验相比，最大的差别是它把“试错”和“大胆”变成了默认选项（这句太AI了😂）。

## 后记

一两场活动当然带不来使命式的改变，但能肉身处在 AI 的时代浪潮里，本身就具有意义。对我自己而言，这是一个提醒：既然有机会在这个特别的时期近距离感受这座城市，就应该多去听、去看、去记录。后面会把这些观察整理成体系，继续在“每周AI观察”里分享真实的现场温度。

vibe coding 让代码的产出速度翻倍；Tech Week 让我再一次意识到，AI 不是远处的风声，而是街角咖啡店里的呼吸。接下来的几周，我会继续把这一切写进日志里，也希望读到这篇文章的你，能找到自己的节奏和伙伴。
